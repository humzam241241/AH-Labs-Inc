# AH Labs frontend design system

## Positioning
AH Labs Inc. is an early-stage engineering studio developing robotics, autonomous systems, embedded electronics, mechanical systems, and applied engineering prototypes. The LiDAR mapping drone is the current flagship venture but the studio is not only a drone company.

## Visual principles
Use an engineering editorial aesthetic: technical documentation, industrial design portfolios, architecture studios, robotics labs, and engineering publications. Prefer strong typography, structured grids, fine borders, technical labels, numbered sections, intentional whitespace, large real project media, and restrained diagrams.

## Anti-patterns
Avoid oversized gradient hero text, purple-blue glow backgrounds, floating glass cards, excessive rounded pills, generic feature grids, animated blobs, fake dashboards, fake metrics, fake client logos, decorative code snippets, repetitive rounded cards, and hype-led SaaS layouts.

## Typography and layout
Use large editorial headings with tight tracking, direct section labels, and high-density metadata tables. Use `site-shell`, `section`, `section-grid`, `h1`, `h2`, `lede`, `body-copy`, `kicker`, and `label` utilities from `app/globals.css`.

## Color and components
Base colors are warm neutral, high-contrast ink, fine border tones, and one restrained rust accent. Buttons are rectangular, border-driven, and purposeful. Placeholder media must be explicitly labelled as placeholders.

## Motion
Motion should be minimal and never essential. Respect `prefers-reduced-motion`. Avoid scroll theatrics.

## Content tone
Write directly and technically. Avoid startup clichés such as revolutionizing, cutting-edge solutions, transforming the future, disrupting industries, industry-leading, next-generation innovation, empowering businesses, and building tomorrow.

## IP disclosure restrictions
Do not publish CAD source files, manufacturing drawings, exact dimensions, full schematics, Gerbers, firmware, source code, complete BOMs, supplier-sensitive information, proprietary calibration procedures, or reproducible implementation instructions.

## Accessibility
Use semantic HTML, visible focus states, strong contrast, accessible labels, keyboard-operable navigation, and responsive layouts without layout shifts.
